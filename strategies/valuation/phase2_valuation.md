### Step 3: 执行定性调整

对 `valuation_computed.md` 中"关键假设清单"表的每个假设，按以下规则执行调整：

#### 3.1 FCF/营收增长率调整（基于 D1）

| D1 信号 | 调整 |
|---------|------|
| 核心经营利润增速 ≈ 报表增速（差 < 2pct）| 无调整 |
| 核心经营利润增速 < 报表增速 - 2pct | 用核心增速替代报表增速 |
| 核心经营利润增速为负（如海尔案例）| 下调至 max(核心增速, 0%) |
| `cash_impact` = "负担" | 在上述基础上额外 -1pct |
| `collection_mode` = "垫资回收" | FCF 可靠性降低，标注警告 |

**海尔智家典型案例**：
```
Python默认: FCF增长率 = 历史营收CAGR(5.72%) × 0.8 = 4.58%
定性信号: D1利润质量分解 → 报表净利润增速+4.39%，但核心经营利润增速-0.14%
         （汇兑收益+1,023.53百万 + 研发削减+644.18百万 掩盖了主业下滑）
调整: 下调FCF增长率至 1.5-2.0%（核心增速更接近真实经营能力）
操作: 从DCF 5×5敏感性表中选取 g≈2.0%/WACC=默认 对应的每股内在价值
```

#### 3.2 永续增长率 g_terminal 调整（基于 D2）

| D2 护城河 | D2 可持续性 | g_terminal (A股) | g_terminal (港美股) |
|----------|-----------|-----------------|-------------------|
| 强 | 高可持续 | 3.0% | 2.5% |
| 较强 | 中等可持续 | 2.5% | 2.0% |
| 中 | — | 2.0% | 1.5% |
| 弱 | — | 1.5% | 1.0% |

从 DCF/DDM 敏感性表中选取对应 g_terminal 列的值。

#### 3.3 Beta/ERP 调整（基于 D3、D4）

| 信号 | 调整 |
|------|------|
| `cyclicality` = "强周期" | Beta +0.2（从敏感性表的更高 WACC 行选取） |
| `management_rating` = "损害价值" | ERP +1.0%（从更高 WACC 行选取） |
| `management_rating` = "观察期" | ERP +0.5% |
| `governance_flags` 有 ⚠️ 标志 | 每个 +0.5% ERP |
| `related_party_risk` = "高" | ERP +0.5% |

#### 3.4 情景权重调整（基于 D3，仅适用于 DCF_Scenarios）

| `cycle_position` | 乐观/基准/悲观 |
|-----------------|---------------|
| 底部 | 35% / 45% / 20% |
| 中段 | 25% / 50% / 25%（默认） |
| 顶部 | 15% / 45% / 40% |

用调整后的权重重新加权三个情景值（值从 valuation_computed.md 读取）。

#### 3.5 DDM 增长率调整（基于 D1 + D5 + 增速趋势）

Python 默认使用 DPS CAGR 作为 DDM Phase 1 增长率。需要两层修正：

**第一层：支付率扩张修正**（几乎总是需要）

| 信号 | 调整 |
|------|------|
| DPS CAGR >> 净利润 CAGR（差 > 10pct） | DPS CAGR 被支付率扩张推高，用净利润增速替代 |
| DPS CAGR ≈ 净利润 CAGR（差 < 10pct） | DPS CAGR 可靠，无需修正 |

**第二层：增速趋势修正**（当公司处于增速拐点时）

| 信号 | 调整 |
|------|------|
| 最新年利润增速 ≈ 5yr CAGR（差 < 5pct） | 使用 5yr CAGR |
| 最新年利润增速 < 5yr CAGR - 5pct，且 D1 确认增速下行 | **使用最新 1-2 年增速**，不用 5yr CAGR |
| D1 核心经营利润增速为负（如海尔模式） | 使用报表增速（而非核心增速）作为 DDM 上限 |

> **原理**：5 年 CAGR 包含了早期高增长年份，当公司处于增速下行拐点时会严重高估未来增速。DDM Phase 1 增长率应与 FCF 增长率调整方向保持一致——如果 FCF 增长率被下调至 0%，DDM 增长率不应仍用 10%+。

#### 3.6 治理折价（基于 D4）

| 信号 | 折价 |
|------|------|
| `management_rating` = "损害价值" | -5% ~ -10% |
| `management_rating` = "观察期" | -3% ~ -5% |
| 无上述问题 | 0% |

对最终加权平均值施加折价。

#### 3.7 控股折价（基于 D6）

| 信号 | 折价 |
|------|------|
| `holding_structure` = false | 0% |
| true + `sotp_discount_pct` 有值 | 使用该值 |
| true + 无精确 SOTP | 10-20%（取决于子公司营收贡献） |

### Step 5: 最终估值判断

用调整后的加权平均值计算安全边际：

| 安全边际 | 判断 |
|---------|------|
| > 30% | 显著低估 |
| 10% - 30% | 低估 |
| -10% - 10% | 合理 |
| -30% - -10% | 偏高 |
| < -30% | 高估 |

**成长高投入样本的结论收敛规则**：

若同时满足以下 3 项中的至少 2 项：
1. 定性报告明确公司质量高/护城河较强/现金质量无明显问题
2. 定性报告或附注增强输入明确存在高资本开支、高 reinvestment、低分配意愿，或 turtle 同类口径对应“股东真实到手回报不足”
3. 安全边际仅落在 `合理` 或 `低估` 边缘（尤其是 0%~15% 的窄幅区间），而不是显著低估

则最终报告**不得**轻易落到“偏中性偏乐观”的成品表达（如“合理偏低”“基本便宜”“质量高所以当前可接受”）。必须把结论显式收敛到以下方向：
- 公司质量高 ≠ 当前股东回报足够
- 高投入/低分配会压制自由现金流可分配性与安全边际
- 即使估值数值接近合理区间，最终落点也应偏向 **审慎/观察/等待更高安全边际** 的解释，而不是鼓励性表述

**措辞要求**：在 Executive Summary、估值结论、风险提示三处至少各出现一次同义表达，明确写出：
- “公司质量高，但当前价格下股东回报未必足够”
- “高投入/再投资需求压制了自由现金流对股东的释放”
- “当前缺的不是公司质量，而是更充足的安全边际/股东回报空间”

若出现上述成长高投入特征，而最终判断仍为“合理”或“低估”，则必须追加一句限制性解释：**该结论仅表示当前价格未明显高估，不等于已满足高确定性买入条件。**

若定性证据已足以说明“自由现金流对股东释放受压”“分配意愿弱”或“股东真实到手回报不足”，则允许在不改动 `valuation_computed.md` 原始数值的前提下，把最终成品落点收敛为更保守的解释性结论。

这一步调整的是**最终报告层的结论落点**，不是改写 Python 计算公式。


### Step 6: 报告组装

读取 `report_template.md`，按模板组装最终报告，关键新增内容：

1. **报告概览 + Executive Summary** — 用调整后的数值
2. **公司分类** — 直接引用 valuation_computed.md 的分类结果
3. **WACC 计算** — 直接引用 valuation_computed.md
4. **定性调整说明**（新增关键章节）：
   - 逐一列出每个假设的调整过程
   - 格式：Python默认值 → 定性信号 → 调整后值 → 依据
   - **若样本属于强周期，且 D1/P13 支持“当期利润质量不差”，必须额外写出一段桥接解释**：先单独判断“当期利润质量是否失真”，再单独判断“这份利润能否代表长期价值锚”，两者不得混写为同一结论。
   - 若 D3 明确利润主要受商品价格/行业周期驱动，则必须明确说明：**利润质量不差** 仅代表本期盈利具备一定真实度，**不等于利润中枢已经稳定**，因此不能把修复期利润直接资本化成长期价值。
   - 这段桥接必须至少覆盖四层逻辑：**2025（或最新年）利润质量不差 → 但价格/周期决定利润中枢波动 → 因此不能把修复期利润直接资本化成长期价值 → 所以下调的不只是参数，而是长期价值锚本身。**
   - **措辞要求**：必须显式出现或同义改写以下三层句意：
     1. **本期利润质量不差 / 没有被一次性项目明显粉饰**
     2. **利润中枢仍受周期与价格驱动，不能把修复期利润直接视为长期稳态利润**
     3. **本次下调针对的是长期价值锚，而不只是折现率、增长率等局部参数**
5. **估值方法详情** — 引用 computed 的计算过程 + 标注调整后选取的敏感性坐标
   - **若为强周期样本，DCF / PE / PEG / DDM 的解释都必须与上面的桥接逻辑保持一致**，统一落到同一结论：本次下调反映的不是对当期利润真实性的否定，而是拒绝将修复期利润直接视为长期资本化基础；不能只分别下调参数而不解释“为什么这些参数共同指向更低的长期价值锚”。
   - **方法级写法要求**：
     - **DCF**：必须明确“终值/长期增长率下调，不是因为利润失真，而是因为长期利润中枢不能按修复期水平资本化”。
     - **PE / PEG**：必须明确“盈利倍数或增长中枢不能机械锚定修复期利润”，避免把“当前盈利真实”写成“当前盈利可长期复制”。
     - **DDM**：必须明确“分红改善更多反映修复期资本配置改善，不足以单独证明长期分红增长中枢已稳定”。
     - 以上三类方法至少各出现一次“修复期利润 ≠ 长期价值锚”的同义表达。
6. **交叉验证** — 包含调整前和调整后两组结果
7. **反向估值** — 引用 valuation_computed.md 第五节，解读市场隐含增长预期；结合定性报告解释增长折价/溢价的合理性
8. **估值结论** — 基于调整后数值 + 反向估值视角
   - **若为强周期样本，估值结论必须显式复述：当前被下调的不是“报表真实性”，而是“把修复期利润当作长期价值锚”的做法。**
   - 估值结论必须把三层逻辑连成一句完整判断：**公司本期利润质量不差 → 但长期利润中枢仍受周期影响 → 因而当前价格若隐含把修复期利润资本化为长期价值，则估值结论应更保守。**
   - **若样本属于混合集团 / 渠道平台型，且 qualitative_report 已明确“核心高质量业务 ≠ 集团合并价值”，则估值结论必须把这层结构约束显式写进最终落点，而不能只停留在解释层。**
   - 具体必须至少覆盖三层句意：
     1. **核心品牌/高质量业务真实存在，但不能机械外推到整个集团合并口径价值**
     2. **流通平台、投资平台、非全资子公司、少数股东权益或结构化主体，会使集团整体估值锚低于核心资产叙事**
     3. **即使当前不直接改写 Python 数值，也必须在最终估值结论中保留集团结构复杂度 / 控股折价 / 分部差异的估值约束视角**
   - **若 D6/SUB 已触发 holding_structure = true，但本轮未直接施加数值折价，也必须明确写出：这不代表集团结构复杂度可以忽略，而只代表本轮选择先把它保留为最终结论层的估值约束。**
9. **关键假设与风险** — 列出核心假设及其定性调整
   - **若为强周期样本，风险提示必须单列一条“长期价值锚风险”**：明确指出风险不在于“利润造假/失真”，而在于“市场或模型错误地把修复期利润当成长期稳态利润”。
   - 风险提示的措辞必须与方法细节、估值结论保持一致，不得一处写“利润质量正常”，另一处又把下调理由写成“利润不可相信”。
10. **免责声明**
