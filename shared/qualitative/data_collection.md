### Peer Evidence / 同业证据包

当本地数据缺少具名同业、全年口径同业指标或竞品对标时，不把零散 WebSearch 结果直接写进正式报告，而是先生成独立中间文件：`peer_evidence.md`。该文件供 qualitative D2 使用，也供报告局限与数据警示判断同业数据缺口。

**输出路径**：`{output_dir}/peer_evidence.md`

**通用红线**：不得硬编码具体样板公司或单一行业同业；同业选择必须来自目标公司的行业、业务、区域、客户结构、上市可比公司或公开披露的竞争格局。若不存在强可比上市公司，显式说明可比边界，不得伪造精确 peer。

**同业选择顺序**：
1. 目标公司年报或公告披露的竞争对手、行业地位、主要市场参与者。
2. 交易所公告、公司公告、行业协会或监管材料中的上市可比公司。
3. 业务模式、区域、客户类型或产品结构相近的上市公司。
4. 若仍不可得，使用行业龙头、行业均值或分部业务坐标，并在 Evidence Gaps 写明限制。

**范围边界**：peer set 控制在 2-4 个具名同业，不追求穷尽同业；指标控制在 4-6 项 WebSearch 能可靠覆盖的全年口径数据。不得扩展成全行业数据库，不为了填满表格去搜难以复核的长尾指标。找不到统一口径就写 Evidence Gaps，不强行凑完整序列。

**年报原文级要求**：同业证据优先做到年报原文级，High 证据必须尽量来自年报、交易所公告、公司公告或审计财报，并记录 `Original wording / 原文摘录`、`Page clue / 页码线索`、`Report section / 年报章节`。同一指标必须优先使用同一口径；无法取得年报原文级证据时，必须在 Evidence Gaps 写明“无法取得年报原文级证据”和后续复核动作。不得用媒体摘要替代 High 证据。

**行业类型化指标模板**：先判断公司类型，再选择 4-6 项最能验证商业质量的全年口径指标；不要把水泥、消费、软件、金融指标互相机械套用。

| 公司类型 | 优先同业指标 |
|---|---|
| 强周期/重资产 | 收入、毛利率、ROE、经营现金流、FCF、Capex/D&A、资产负债率、吨价 / 吨成本 / 吨毛利（若披露） |
| 制造业/设备 | 收入增速、毛利率、费用率、研发率、存货/应收、现金转换、海外收入占比、客户集中度 |
| 消费/品牌 | 收入增速、毛利率、渠道结构、单店/单客经济、广告费用率、存货周转、现金质量 |
| 软件/互联网/轻资产 | 订阅/服务收入、毛利率、研发率、销售费用率、客户留存、海外收入、FCF margin |
| 金融/保险 | 净息差、不良率、拨备覆盖率、资本充足率、ROE、负债成本、分红能力 |
| 行业无法归类 | 收入、毛利率、ROE、经营现金流、FCF、资产负债率，并说明只能做粗颗粒同业坐标 |

**搜索关键词规则**：每个 peer 的关键搜索必须包含“年报”“年度报告”“全年”或 “annual report” 之一，确保竞品对标使用全年口径。优先使用公司年报、交易所公告、公司公告、监管披露；行业协会、公司官网、业绩发布为次优；媒体、百科、财经网站摘要只能补背景。

**置信度规则**：
- `High`：年报、交易所公告、公司公告、审计财报。
- `Medium`：行业协会、监管机构、公司官网、正式业绩发布。
- `Low`：媒体报道、财经网站摘要、非官方数据库。

低置信来源不得支撑核心评级。正式报告可用 High 证据支撑 D2 同业表和护城河判断；Medium 证据只作辅助背景；Low 证据只能提示方向或缺口，不能作为“护城河成立”或“商业质量强”的主证据。

### D3 轻量外部周期证据

强周期公司可以在不新增庞大的周期数据库的前提下，补充 2-3 个外部周期变量，用于解释 D3 的需求、价格、成本和 ROE/FCF 传导。该补充只服务周期判断，不替代本地财务数据，也不扩展为完整行业数据工程。

**范围边界**：只采集年度或全年口径、公开来源清楚、WebSearch 能可靠覆盖的变量；找不到就写缺口，不使用零散月度新闻拼接长期序列。

| 变量类型 | 搜索关键词示例 | 使用方式 |
|---|---|---|
| 需求 / 产量 | "{行业} 2025 全年 产量 需求 年报" | 判断需求是否修复，不能单独支撑评级上修 |
| 价格趋势 | "{行业} 2025 全年 价格 指数" | 验证毛利率改善是否来自价格端 |
| 主要成本变量 | "{主要原材料} 2025 全年 价格 成本" | 验证成本下降是否可持续 |

若只能找到半年、月度或媒体片段，必须在 Evidence Gaps 或报告局限中说明，不得伪造成年度序列。D3 只需要判断外部变量是否与收入、毛利率、ROE、FCF 同向改善，不需要覆盖所有行业指标。
