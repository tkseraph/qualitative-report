# 定性报告数字写作补充规则

> 本文件补充 `agents/writing_style.md`；若与 `shared/report_contract.json` 或 `validate_reports.py` 冲突，以本地机器契约为准。

## 核心规则

1. **结论先行**：每个维度第一段先给明确判断。
2. **Lead with numbers（数字先行）**：先给数值、比较基准和口径，再写“改善、承压、领先”等判断。
3. **数字可追溯**：CM、DP、年报页码和外部来源定位写入内部证据账本；公开报告只保留来源名称、年份、页码或表级口径，不得出现 `[src: ...]`。
4. **CM 不重算**：CM 覆盖的亿元换算、同比、多年统计、分红支付率和 PE 网格直接引用；其他计算展示数据、公式、结果。
5. **口径先说明**：同一指标出现母公司/合并、季度/全年、调整前/后口径时，首次出现即标明。
6. **推断不越界**：推断必须明确写成推断；没有生效监管结论时，不使用“造假、舞弊、操纵、欺诈”等定性。

## 单位规范

| 场景 | 单位 | 来源 |
|---|---|---|
| 报告正文 | 亿元或万元，保留合理小数 | 优先引用 CM§1 |
| 结构化参数 | 遵循现有 output schema | data_pack 对应章节 |
| 原始数据文件 | 文件声明的原始单位 | Tushare / 年报 |

## 模糊量化词替换

| 避免单独使用 | 改写方式 |
|---|---|
| 大幅、显著、明显增长/下滑 | `+X%（同比，合并口径）` 或 `从 A 亿元变为 B 亿元` |
| 优于行业、领先同业 | 列出目标公司与具名同业的同口径数字 |
| 高估值、低负债 | 给出 PE/PB/负债指标与可比基准 |
| 现金充裕、资金紧张 | 给出现金、短债和覆盖倍数 |
| 有定价权 | 给出价格、销量、毛利率与同业变化的共同证据 |

行业经验速查表只能帮助发现异常，不能替代当期证据、不能直接生成阈值或评级。
